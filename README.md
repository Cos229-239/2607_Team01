# API Plan
Our project uses TheMealDB for meal search and meal details. 
- Search by main ingredient www.themealdb.com/api/json/v1/1/filter.php?i=chicken_breast
- Search by meal category www.themealdb.com/api/json/v1/1/filter.php?c=Seafood
- Search meal by name www.themealdb.com/api/json/v1/1/search.php?s=Arrabiata
